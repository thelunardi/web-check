# web-check

CLI em Go para monitorar a disponibilidade de um site via linha de comando.

## Funcionalidades

- Iniciar monitoramento de um site e verificar o status da resposta HTTP
- Exibir logs (em desenvolvimento)
- Sair do programa

Veja detalhes em [docs/funcionalidades.md](docs/funcionalidades.md).

## Requisitos

- Go 1.25.4 ou superior

## Como executar

```sh
go run main.go
```

## Uso

Ao iniciar, o programa exibe um menu:

```
1- Iniciar Monitoramento
2- Exibir Logs
0- Sair do Programa
```

Digite o número da opção desejada e pressione Enter.
